# 归潮 · V3 解剖室

本轮先完成同类游戏与素材来源调研，再修改造型、解剖差分和经营选择。标题页仍只有“归潮”“开始旅途”。

## 运行

- Windows：`Build/ReturnTide.exe`。
- Unity 主场景：`Assets/ReturnTide/Workshop/Scenes/Workshop.unity`。
- 一键生成：`Tools → 归潮 Return Tide → 一键生成可编辑关卡`。
- 回车或点击开始；Esc 暂停/返回；Tab 在台面和交易之间切换。

V3 使用独立经营存档键，保留 V2 的旧存档。资金、设备、库存、订单、纯度和已完成的组织移除步骤会保存；当前未完成的划线与敲击次数不保存。

## 解剖与策略

1. 按 1 选刀，从亮点沿弧面切线拖动，切开皮肤和肌肉。
2. 按 2 选锤敲碎骨片；不同标本需要的敲击次数不同。碎后再敲、用错误工具处理柔软组织会降低纯度。
3. 按 3 选镊子，将碎骨、普通器官、晶核拖入右侧回收盘。
4. 灯囊鳗的绿色毒囊必须进入左侧隔离盘。放错盘会损失 25 纯度，并影响晶核售价及完整晶核订单。
5. 买激光后按 4 处理外骨骼；探针购买后按住 Q 查找藏核器官。
6. 自动剥皮提高处理速度，但灯囊鳗损失 18 纯度、棘晶鳐损失 10。交易界面可以启用/停用自动剥皮；处理脆弱标本前可选择手工。
7. 完成晶核收取后点击“选择来货”或按 N，在稳定货源和当前解锁的风险标本之间选择。未配激光的外骨骼鱼可以退回换货，退回不再凭空奖励金币。

委托依次要求：4 份鱼肉、纯度至少 85 的晶核、3 份异变组织。委托交付会消耗相应物品；直接出售后不能再拿同一件物品交付。组织同时用于设备，因此需要决定出售、交单或投入升级。

第一个订单后开放灯囊鳗，第二个后开放棘晶鳐。返航要求完成 3 份委托，并支付资金和组织。

## 四种独立标本

| 标本 | 核心差分 |
| --- | --- |
| 鳃鳞鲈 | 收束鱼体、叉尾、连续背皮；每片肌肉产 2 份鱼肉，适合稳定交单 |
| 锈甲魟 | 较宽体形、弧面叠甲；必须用激光，骨片敲击 4 次 |
| 灯囊鳗 | 细长身体、灯饵、口须、弯曲尾部；毒囊隔离，自动剥皮有风险 |
| 棘晶鳐 | 展开的扇形翼鳍与不对称晶簇；薄骨只需敲击 2 次，重视完整度 |

每种模型都有独立 FBX、Blender 源文件、预制体和 SpecimenProfile 配置。并非只在同一预制体上换颜色。

## 美术修改

科研员：连续刘海、平贴眼部、分离的护目镜框与镜片、实验服翻领/口袋/收腰、带手指的手套。鱼贩子补了帽纹、眉眼、胡须与围裙细节。

工作间：重建倒角搪瓷台、排水槽、卷边浅托盘、隔离盘、瓶颈与瓶盖、铜管、压力表、解剖挂图、擦拭布与交接票据。台灯集中照亮工作面，人物使用单独柔光，避免脸部和晶簇过曝。

动画仍是工作台程序关节动作，尚非全身蒙皮骨骼与手指物理系统。

## 编辑位置

- `Workshop/Settings/Balance.asset`：价格、委托报酬、完整度要求和返航门槛。
- `Workshop/Settings/Specimen_*.asset`：各物种价格、产肉量、骨片强度、毒囊位置、机器风险与解锁条件。
- `Workshop/Prefabs/Specimen_*.prefab`：15 个独立组织、碰撞体、切线节点和器官引用。
- 场景 `03 · 镜头机位`：全景、台面、交易、返航机位。
- 科研员 `WorkshopAnimator`：呼吸、眨眼、头部注视与双臂动作。
- 场景 `05 · 界面`：独立文字、按钮、来货选择与交易布局。

以上 Workshop 路径均相对于 `Assets/ReturnTide/`。

`ArtSource/create_v3_models.py` 重建人物和四种标本；`create_v3_props.py` 重建手术台与器皿。对应 `.blend` 全部在 ArtSource 中。

## 研究与验收

- `ArtSource/ResearchV3/DIRECTION.md`：官方资料、差分表、模型验收标准和策略层次。
- `ArtSource/ResearchV3/ASSET_OPTIONS.md`：核对过的外部素材来源与适用边界；本轮没有购买或混入这些素材。
- `EvidenceV3/00-character-detail.png`：人物实机近景。
- `EvidenceV3/01-room.png`：整体房间。
- `EvidenceV3/02-reef.png` 至 `06-crystal-ray.png`：同机位标本与内部差分。
- `EvidenceV3/checks.txt`：Unity Play Mode 检查，包括弧面屏幕划线、射线夹取、污染、纯度折价、订单、解锁、机器启停、返航与 Windows 构建。

这是继续打磨中的单房间可玩版本。商业成品级的手绘纹理、完整骨骼动画、多日订单编排和长期经济平衡不在本轮已完成范围内。
