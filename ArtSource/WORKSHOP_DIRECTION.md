# 归潮 · 解剖室版方向与参考

## 参考依据

- [Papers, Please 官方工作台截图](https://papersplea.se/img/Shot02-Booth.png)：工作空间本身承载物品和操作。本版据此把鱼、刀、骨锤、镊子、托盘、收购铃保留为场景对象。
- [DREDGE 开发商页面](https://www.blacksaltgames.com/)：出售渔获、研究设备、升级能力以接触更稀有目标。本版转化为“解剖收益 → 工具升级 → 打开外骨骼 → 更贵的晶核”，并让异变组织存在出售或投入设备的取舍。
- [Surgeon Simulator 官方商店页](https://store.steampowered.com/app/233720/Surgeon_Simulator/)：以实体工具和身体部件构成操作。这里采用刀、锤、镊子的不同动作，但没有采用该作刻意笨拙的逐指控制。
- [The Mortuary Assistant 开发商页面](https://dreadxp.itch.io/the-mortuary-assistant)：以房间内的职业操作推动恐怖氛围。这里用深夜工作间、标本瓶与变异鱼承载背景。

以上是参考与设计推导，不是对这些游戏 UI 规则的逐项复刻。没有导入其图片、模型、音乐或界面资产。

## 已确定的本版规则

标题页只出现“归潮”“开始旅途”。删除工作室名、英文副标题、章节编号、宣传短句与解释性结语。
游戏中只显示当前工具与可点击的交易入口；悬停时给一个动作提示。库存获得后才显示，钱在首次交易后出现。交易价格只在交易状态显示，使用文字选项和渐隐衬底，没有大块方形菜单。

场景采用低模实体小房间，主色为深海蓝、灰绿与旧黄铜；实验服和操作衬垫使用暖白。台灯集中照亮解剖面，冷窗光和晶核微光补充层次。肉、器官与外骨骼是独立模型部件，组织颜色抽象化，不追求写实血腥。

镜头分为房间全景、解剖特写、鱼贩子交易、返航门四个可编辑机位。切换采用 0.85 秒缓入缓出；操作中固定镜头，不做持续摇晃、自动旋转或追踪缩放，以免妨碍鼠标划线。过渡时暂停台面拾取。

科研员使用可编辑关节的程序动画：呼吸、眨眼、头部注视、点头、双臂伸取、敲击起落与夹取收手。工具跟随操作位置，骨锤、刀与激光具有不同动作和声音。这不是完整动作捕捉或通用人形骨骼动作库；本版围绕工作台动作制作。

## 已实现循环

三片皮肤沿线划开 → 两片肌肉切开 → 三组骨片先敲碎再用镊子拖入托盘 → 移开器官搜寻晶核 → 用镊子取出晶核 → 向鱼贩子出售。

鱼肉、皮和骨随货物出售；异变组织单独保留，可逐份卖出或用于工具。激光解锁外骨骼，剥皮机自动处理新来鱼的表皮，升级刀扩大划线容错，探针在按住 Q 时提示藏核器官。

来货包含普通鱼、外骨骼鱼、触须变异鱼和金冠彩蛋鱼。金冠鱼晶核售价为普通晶核的五倍。没有激光时可以退回外骨骼鱼，避免经济死锁。

回归以修复湖岸返航信标收束当前经营轮次，镜头转向打开的湖岸门。结尾回到两项菜单，没有旁白和道理总结。

目前是单房间经营原型；保留上一版鱼腹场景作为旧版本，主入口和构建已经切换到解剖室。
